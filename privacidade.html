Política de Privacidade — FotoVitrine

Última atualização: junho de 2026

1. Dados Coletados

Autenticação: ao fazer login com o Google, o FotoVitrine recebe seu nome e e-mail. Esses dados são armazenados no Supabase (provedor de banco de dados) exclusivamente para controle de acesso e identificação da conta.

Conteúdo do usuário: as imagens capturadas, vídeos e artes criadas com o App ficam armazenadas localmente no seu dispositivo. Apenas logos, ícones e configurações de empresa são enviados para o Supabase para fins de sincronização entre dispositivos.

Dados de pagamento: o FotoVitrine não coleta, processa ou armazena dados de cartão de crédito, CPF, endereço ou qualquer dado financeiro. Todo o processamento de pagamento é realizado exclusivamente pela Google Play Store.

2. Compartilhamento de Dados

O FotoVitrine não vende, aluga ou compartilha dados pessoais com terceiros. Os dados de autenticação são processados pelo Google (Google Sign-In) e Supabase, ambos provedores que seguem rigorosos padrões de segurança e conformidade.

3. Permissões do Dispositivo

O App solicita acesso:

  • Câmera: para captura de fotos e vídeos de produtos.
  • Microfone: para gravação de vídeos.
  • Armazenamento: para salvar e carregar as artes criadas.

Nenhuma permissão é usada para fins não relacionados ao funcionamento do App.

4. Segurança

Toda comunicação entre o App e o Supabase é criptografada via HTTPS. Tokens de autenticação são armazenados de forma segura no sistema Android. O FotoVitrine adota boas práticas de segurança, incluindo a não exposição de chaves de API no código-fonte.

5. Exclusão de Dados

O usuário pode solicitar a exclusão dos seus dados a qualquer momento enviando um e-mail para fotovitrine1@gmail.com. Responderemos em até 15 dias úteis. A exclusão inclui a remoção dos dados de autenticação e configurações armazenados no Supabase.

6. Alterações nesta Política

Esta Política pode ser atualizada periodicamente. Alterações substanciais serão comunicadas por e-mail ou no próprio App. O uso continuado do App após as alterações constitui aceitação da nova versão.
